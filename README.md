# Agafay Adrenaline Adventures

Build a premium, high-conversion Quad/ATV booking platform with a breathtaking, modern design and a fully functional admin backend. The location is specifically set in Agafay, Marrakech—one of the best places for tourism and desert off-roading. The tech stack must use React/Next.js, Tailwind CSS, Shadcn UI components, and Supabase for the database and backend logic.

Design & UI/UX Vibe (The "Crazy Good" Factor):

Theme: Dark mode by default with aggressive, energetic accent colors (like neon orange or electric green) to simulate adrenaline and the Moroccan desert terrain.

Animations: Smooth reveal animations on scroll (using Framer Motion), micro-interactions on buttons, and a premium parallax scrolling effect across the page.

Frontend Landing Page Sections:

Hero Section: A full-screen immersive video background banner of quads driving through the stunning desert dunes of Agafay, Marrakech. Include a dynamic parallax effect as the user scrolls down. Large, bold, modern typography for the headline (e.g., "Conquer the Agafay Desert"), a subheadline highlighting Marrakech's premier quad experience, and a glowing, prominent "Book Your Ride" CTA button.

Highlights/Features: A sleek grid with custom icons highlighting key benefits (e.g., Explore the Agafay Oasis, Expert Local Guides, Top-Tier Gear, Unforgettable Sunset Trails).

Services/Tours: Beautiful, large cards showcasing different tour options (e.g., Agafay Sunset Drive, Extreme Palmeraie Track, Atlas Mountain Footprints). Each card should have a high-quality image, duration, difficulty level, and a "View Details" button.

Pricing Section: Clear, stylish pricing tiers (Hourly, Half-Day, Full-Day) with a list of what's included in each package (e.g., traditional Moroccan tea break, safety gear).

Reviews/Testimonials: A sliding carousel featuring glowing customer reviews praising the Marrakech experience, star ratings, and profile pictures.

Footer: Clean layout with social links, contact info, an embedded map pointing specifically to the Agafay desert in Marrakech, and terms/policies.

Backend & Admin Dashboard Requirements (via Supabase):

Create a secure /admin route with a sleek dashboard interface.

Quad Management: A CMS interface to Create, Read, Update, and Delete (CRUD) quad inventory. Fields should include: Quad Name, Engine Size (cc), Image Upload, Status (Available/Maintenance), and Daily/Hourly Rate.

Offers Management: A section to post and manage special promotional offers (e.g., "Marrakech Summer Discount", "Group Rates") with start/end dates and discount percentages.

Bookings Overview: A simple table view to see incoming booking requests (Customer Name, Date, Tour Selected, Quad Selected, Status).

Please generate the complete UI layout, set up the necessary state management, wire up the Shadcn UI components, and create the schema structure needed for the Supabase integration. Make the UI pixel-perfect and responsive across all mobile and desktop devices.
